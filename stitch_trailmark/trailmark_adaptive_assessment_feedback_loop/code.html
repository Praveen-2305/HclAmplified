Which activation function is most commonly used in the hidden layers of deep neural networks to mitigate the vanishing gradient problem?

lightbulb

Correct! ReLU is the most common choice as it outputs the input directly if it is positive, otherwise, it outputs zero. This simplicity helps prevent vanishing gradients during backpropagation.

Conceptual Breakdown

  • Sigmoid/Tanh: These saturate at high/low values, causing gradients to vanish, which slows down learning in deep networks.
  • Softmax: Primarily used in the output layer for multi-class classification, not typically for hidden layers.
