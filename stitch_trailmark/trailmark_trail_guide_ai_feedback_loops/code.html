Misconception Alert

It's a common mistake to think ReLU is linear because it looks like a straight line. However, the "bend" at zero is what provides the critical non-linearity needed for deep networks.

Bridging Concept

Think of ReLU as a logical gate: it either lets the signal pass through unchanged or blocks it entirely. This simple switching behavior allows the network to learn complex, piecewise linear approximations of any function.
